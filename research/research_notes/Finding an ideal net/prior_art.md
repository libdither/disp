# Prior art: defining and searching for an ideal computational system

Question: how have others defined, characterized, or searched for minimal, canonical or optimal computational systems, and what can an objective over interaction systems (finitely many agent kinds, one principal port each, at most one rule per pair) borrow?

Every quote below was fetch-verified with `scripts/verify-source.sh` (92 quotes, 2026-11-12). *Inference:* marks my own reasoning.

## 1. Universality as a characterization

**Lafont's interaction combinators.**
- Headline: a system ["with only three symbols and six rules, is a universal model of distributed computation"](https://dcreager.net/pdf/Lafont1997.pdf#page=1). Theorem 1: ["Any interaction system can be translated into the system of interaction combinators"](https://dcreager.net/pdf/Lafont1997.pdf#page=14).
- "Universal" here is stronger than Turing-complete. The translation maps each symbol to a small net and must be compatible with reduction, ["preserving the essential properties of computations, such as the complexity and the degree of parallelism"](https://dcreager.net/pdf/Lafont1997.pdf#page=2). The step overhead is bounded: with L and M ["the minimal (resp. the maximal) length of all those reductions"](https://dcreager.net/pdf/Lafont1997.pdf#page=13), a source run of n steps becomes between Ln and Mn target steps. So a Turing machine does not count: ["Turing machines can be seen as particular interaction systems, but such systems are intrinsically sequential"](https://dcreager.net/pdf/Lafont1997.pdf#page=2) and cannot be universal in this sense.
- The design was not searched for. It ["has been obtained by a kind of distillation"](https://dcreager.net/pdf/Lafont1997.pdf#page=2) from a bigger system for linear-logic boxes. The lesson Lafont draws is that ["the fundamental laws of computation are commutation and annihilation"](https://dcreager.net/pdf/Lafont1997.pdf#page=2).
- **Minimality (Section 2.8): a necessity argument by invariants, not a full proof.** Each rule is the unique rule with some property. γδ (commutation) ["is the only rule which increases the number of cells"](https://dcreager.net/pdf/Lafont1997.pdf#page=22). εε ["is the only rule for which the right member is empty"](https://dcreager.net/pdf/Lafont1997.pdf#page=22). One of γε/δε is the only way to make more erasers. One of γγ/δδ is the only rule whose right side is a nonempty wiring. In fact ["the system remains universal if one removes"](https://dcreager.net/pdf/Lafont1997.pdf#page=22) δε (5 rules suffice). On fewer kinds: Béchet found a ["universal interaction system with only two symbols and three rules"](https://dcreager.net/pdf/Lafont1997.pdf#page=22), but with one complicated rule; one symbol cannot work. Lafont only conjectures: ["we conjecture that our system of interaction combinators is essentially the simplest one satisfying Theorem 1"](https://dcreager.net/pdf/Lafont1997.pdf#page=22).
- Symmetric combinators (γγ made the same as δδ): this system ["is not universal in the technical sense of Theorem 1"](https://dcreager.net/pdf/Lafont1997.pdf#page=29), yet Lafont says it has the same expressive power. So "universal" depends on the translation notion you fix.
- Reversibility: Lafont also says ["we interpret the nets of combinators as reversible 2-stack machines"](https://dcreager.net/pdf/Lafont1997.pdf#page=22).

**Béchet & Lippi** state the same notion with morphisms. A system U is universal when ["A hard interaction system U is said to be universal if for any hard interaction system"](https://users.polytech.unice.fr/~lippi/r/bechet-lippi-bool.pdf#page=5) I there is a simulation of I by U. A simulation is a homomorphism (each symbol maps to a net) that commutes with reduction. Their "hard" (circuit-like) universal system has 17 symbols, and they say ["This system is certainly not optimal in the sense that it is surely possible to find a universal boolean interaction system with less symbols"](https://users.polytech.unice.fr/~lippi/r/bechet-lippi-bool.pdf#page=11). That is a second documented case where adding a constraint (here, hardware-friendliness) raises the minimum size.

**Mazza: semantics of the symmetric combinators.** Because of universality, ["the symmetric interaction combinators stand out as a prototypical language"](https://arxiv.org/pdf/0906.0380#page=2), like λ-calculus for functions. He proves a separation theorem: ["any non-trivial congruence containing β-equivalence cannot equate two total βη-different nets"](https://arxiv.org/pdf/0906.0380#page=14). His observational equivalence is maximal: ["indeed the greatest consistent sensible theory"](https://arxiv.org/pdf/0906.0380#page=4). He gives a fully abstract model, and its observables tie to Girard's paths: ["observable axioms are related to a certain kind of paths of Girard's geometry of interaction"](https://arxiv.org/pdf/0906.0380#page=3).

**Initiality / canonicity in a category.** No source found that states interaction combinators are initial or terminal in a category of interaction systems. *Inference:* translations go *into* the combinators, so at best they are weakly terminal (every system maps in, not uniquely), and so is every other universal system. Universality alone therefore does not pick out one system; minimality has to be added on top.

## 2. Size of self-interpreters as a measure

**Tromp (binary λ-calculus, BLC).** Main theorem: ["There is a self-interpreter E of size 206"](https://tromp.github.io/cl/LC.pdf#page=5) bits. For combinatory logic: ["There is a self-interpreter F for Combinatory Logic of size 263"](https://tromp.github.io/cl/LC.pdf#page=10). He turns the interpreter into a universal machine and so ["we propose a concrete definition of Kolmogorov complexity that is (arguably) as simple as possible"](https://tromp.github.io/cl/LC.pdf#page=11). The language choice matters only up to the usual constant: ["the notion is actually invariant up to an additive constant"](https://tromp.github.io/cl/LC.pdf#page=10). He uses self-interpreter size to compare languages: Penrose's universal Turing machine ["whose own encoding is an impressive 5495 bits in size"](https://tromp.github.io/cl/LC.pdf#page=11), and a ["BF self-interpreter of only 423 instructions"](https://tromp.github.io/cl/LC.pdf#page=11) (about 1269 bits). Some tiny objects were found by exhaustive search: ["the smallest possible fixpoint combinator as verified by exhaustive search by computer"](https://tromp.github.io/cl/LC.pdf#page=10). He conjectured a floor: ["We conjecture that any self-interpreter for any binary representation of lambda calculus must be at least 24 bytes"](https://tromp.github.io/cl/LC.pdf#page=7). His page now reports a community result ["shrinking the self interpreter to 162 bits and the universal machine to 184 bits"](https://tromp.github.io/cl/cl.html). *Inference:* 162 bits is about 20 bytes, under the 24-byte conjecture, so the floor is not firm. Hand-optimized records keep dropping, which makes "size of the best known self-interpreter" a noisy objective unless it is searched for exhaustively.

**Mogensen.** A higher-order term encoding ["leads to an exceedingly small and elegant self-interpreter"](https://www.cambridge.org/core/services/aop-cambridge-core/content/view/4727ED102FD8F5C5950EBBFE776E8C69/S0956796800000423a.pdf/efficient_selfinterpretation_in_lambda_calculus.pdf#page=1). It is measured on speed too: self-interpreter and self-reducer run ["being about 35 and 50 times slower"](https://www.cambridge.org/core/services/aop-cambridge-core/content/view/4727ED102FD8F5C5950EBBFE776E8C69/S0956796800000423a.pdf/efficient_selfinterpretation_in_lambda_calculus.pdf#page=1) than direct execution. So size and overhead are two separate axes.

**Jones optimality (Jones, Gomard, Sestoft).** Specializing a self-interpreter to a program p should give back p: the goal is that ["all overhead caused by sint's interpretation has been removed by mix"](https://web.archive.org/web/20240926133440id_/https://www.itu.dk/people/sestoft/pebook/jonesgomardsestoft-a4.pdf#page=149). An optimal specializer is one ["able to remove all such overhead"](https://web.archive.org/web/20240926133440id_/https://www.itu.dk/people/sestoft/pebook/jonesgomardsestoft-a4.pdf#page=137). They warn that the test can be gamed: a specializer that spots sint and ["outputs its second argument unaltered"](https://web.archive.org/web/20240926133440id_/https://www.itu.dk/people/sestoft/pebook/jonesgomardsestoft-a4.pdf#page=149) passes trivially.

**Brown & Palsberg (typed self-interpreters).** Against the folklore that ["a self-interpreter for a strongly normalizing λ-calculus is impossible"](http://web.cs.ucla.edu/~palsberg/paper/popl16-full.pdf#page=1), they build one for Fω. Their point: what counts as a self-interpreter depends on what counts as a representation. They require that ["the representation function must be total (all legal terms can be represented) and injective"](http://web.cs.ucla.edu/~palsberg/paper/popl16-full.pdf#page=11) and produce normal forms, because ["Every language trivially supports shallow self-embedding"](http://web.cs.ucla.edu/~palsberg/paper/popl16-full.pdf#page=12).

**Jay (tree calculus).** No quoting step: ["the programs are already data structures, so that no pre-processing is required"](https://raw.githubusercontent.com/barry-jay-personal/tree-calculus/master/tree_book.pdf#page=18). The reflective programs include ["a size program that can compute its own size"](https://raw.githubusercontent.com/barry-jay-personal/tree-calculus/master/tree_book.pdf#page=5) and self-evaluators shown to ["do no more evaluation than allowed by the corresponding evaluation strategy"](https://raw.githubusercontent.com/barry-jay-personal/tree-calculus/master/tree_book.pdf#page=21). That is a Jones-style "no extra work" claim, made per strategy. The book prints the whole self-evaluator as a string: ["Figure 1.1 shows the encoding of the branch-first self-evaluator"](https://raw.githubusercontent.com/barry-jay-personal/tree-calculus/master/tree_book.pdf#page=19) in ternary Polish notation. I found no stated node count in the book.

*Inference:* what the four agree on. A self-interpreter is a fair measure only if the representation is fixed in advance (Brown–Palsberg, Jay), its size is counted in a fixed encoding (Tromp), and its overhead is counted as well (Mogensen, Jones). Any one of these alone can be gamed.

## 3. Searches over rule spaces

**Small universal Turing machines (Neary & Woods survey).** Since Shannon, ["where size is the number of states and symbols"](https://arxiv.org/pdf/1110.2230#page=1). For decades ["the smallest universal Turing machines seemed to be exponentially slow"](https://arxiv.org/pdf/1110.2230#page=2), until they showed the Minsky/Rogozhin-style machines run in polynomial time. Loosening the input convention (an infinitely repeated blank word) shrinks machines: ["It is not difficult to see how this generalisation can help to reduce program size"](https://arxiv.org/pdf/1110.2230#page=5). Hence ["When discussing the complexity of small machines the issue of encodings becomes very important"](https://arxiv.org/pdf/1110.2230#page=13). Lower bounds are hard: ["finding new lower bounds on universal program size is tricky"](https://arxiv.org/pdf/1110.2230#page=14). These machines were built by hand from tag-system simulations, not found by search.

**Wolfram / Cook (rule 110).** Wolfram enumerated the whole space: ["There turn out to be a total of 256 possible sets of choices"](https://www.wolframscience.com/nks/p53--more-cellular-automata/#content). Cook's method inverts design: rather than build a universal automaton, ["take the very simplest one that naturally exhibits complex behavior"](https://wpmedia.wolfram.com/sites/13/2018/02/15-1-1.pdf#page=2) and find universality inside it. His guard against cheating: ["This compiler, like the data encoder, is required to always finish within a predictable amount of time"](https://wpmedia.wolfram.com/sites/13/2018/02/15-1-1.pdf#page=3). Wolfram's conclusion: ["universality is possible even among cellular automata with the very simplest kinds of"](https://files.wolframcdn.com/pub/www.wolframscience.com/nks/nks-ch11-sec11.pdf#page=2) underlying rules.

**Self-reproducing cellular automata (Codd, Langton, then search).** Codd hand-simplified von Neumann's design to a rule that ["requires just 8-states per cell"](https://www-users.york.ac.uk/~gt512/BIC/langton84.pdf#page=2). Langton asked the converse: ["How simple can a machine become while still retaining the capacity to reproduce itself"](https://www-users.york.ac.uk/~gt512/BIC/langton84.pdf#page=2). Minimizing needed a new anti-triviality criterion. The old one, that ["it has generally been required that any self-reproducing configuration must be capable of universal construction"](https://www-users.york.ac.uk/~gt512/BIC/langton84.pdf#page=3), was too strong. He replaced it with "the copy is actively directed by the structure", but ["not to the extent that the structure is merely passively copied by mechanisms built into the transition function"](https://www-users.york.ac.uk/~gt512/BIC/langton84.pdf#page=3). Langton's loop was designed by hand. Later, Lohn and Reggia note that ["models of self-replication using cellular automata have been manually designed"](https://cba.mit.edu/events/03.11.ASE/docs/Lohn.pdf#page=1) and instead searched rule tables with a genetic algorithm. Its ["multiobjective fitness function consisting of three independent measures"](https://cba.mit.edu/events/03.11.ASE/docs/Lohn.pdf#page=1) were growth, relative positioning, and number of replicants. The found replicators ["compare favorably in terms of simplicity with those generated manually"](https://cba.mit.edu/events/03.11.ASE/docs/Lohn.pdf#page=1). (Byl's smaller hand-made loop is cited there but I could not reach Byl's paper.)

**Busy beaver BB(5).** ["The proof enumerates 181,385,789 Turing machines with 5 states"](https://arxiv.org/pdf/2509.12337#page=1). That is about 16.7 trillion naive machines cut down by Tree Normal Form. TNF defines transitions only when a run reaches them, and orders unseen states so that renamings are skipped: ["State/symbol permutation divides the syntactic space size by a factor of"](https://arxiv.org/pdf/2509.12337#page=11) (n−1)!(s−1)!. Each machine then goes through a pipeline of partial deciders: ["there is no universal decider and all the craft resides in creating deciders"](https://arxiv.org/pdf/2509.12337#page=4). The leftovers needed hand proofs: ["13 Sporadic Machines were not solved by deciders"](https://arxiv.org/pdf/2509.12337#page=4). Everything is checked in Coq.

**Interaction nets specifically.** One web search found no exhaustive enumeration of small interaction systems. *Inference:* a TNF-style lazy enumeration (define a rule only when a reachable active pair needs it, and break agent-renaming symmetry) looks new for this setting.

## 4. Synthesizing rewrite rules automatically

**Superoptimization.** Massalin: ["the superoptimizer finds the shortest program to compute a function"](https://web.stanford.edu/class/cs343/resources/superoptimizer.pdf#page=1), and the key is ["a probabilistic test that makes exhaustive searches practical"](https://web.stanford.edu/class/cs343/resources/superoptimizer.pdf#page=1). Random test vectors filter candidates and a full check confirms the survivors. He adds ["a method for pruning the search space while maintaining the guarantee of optimality"](https://web.stanford.edu/class/cs343/resources/superoptimizer.pdf#page=2). STOKE drops exhaustiveness: ["transformation correctness and performance improvement are encoded as terms in a cost function"](https://arxiv.org/pdf/1211.0557#page=1), explored by MCMC sampling.

**Rule inference with e-graphs.** Ruler's stated objective: ["smaller rulesets of more general, less redundant rules are desirable"](https://arxiv.org/pdf/2108.10436#page=3). Mechanics: each term carries a ["characteristic vector (cvec) that stores the result of evaluating"](https://arxiv.org/pdf/2108.10436#page=7) it on sample inputs. Matching vectors propose rules, and the next round ["only enumerates over the canonical representatives from the equivalence classes"](https://arxiv.org/pdf/2108.10436#page=8) modulo rules already found. Enumo makes this programmable: ["term enumeration strategies and rulesets are first-class values"](https://ajpal.github.io/assets/files/enumo-paper.pdf#page=3), and a user can control ["how much redundancy is permissible in the ruleset, measured via"](https://ajpal.github.io/assets/files/enumo-paper.pdf#page=6) derivability. Kissinger's string-graph (diagram) version uses the same pruning: ["It does this by only enumerating terms that are irreducible with respect to a rewrite system"](https://arxiv.org/pdf/1203.0202#page=17). That one is graph rewriting, so it is the closest prior art to synthesizing net rules.

**SAT/SMT for rewrite systems.** Zantema encodes rewriting properties as constraints and lets a solver find a system; with it ["we fully automatically find a TRS that is locally confluent but not confluent"](https://hzantema.win.tue.nl/rta13.pdf#page=1). For term rewriting systems he must restrict the class, because ["describing properties like termination and confluence in a SAT formula is much harder"](https://hzantema.win.tue.nl/rta13.pdf#page=2).

**Interaction net rules.** I found no paper that synthesizes interaction-net rules by search or solver (two web searches). *Inference:* interaction systems are friendlier to SAT than term rewriting. Confluence holds by construction (Section 5), and a rule's right side is a bounded net, so a fixed-size rule table is a finite set of Boolean variables.

## 5. Principled criteria: what forces a design

**Strong confluence comes free from the shape of the rules.** Lafont's Proposition 1: because rules fire only on principal-port pairs, ["two such instances are necessarily disjoint"](https://dcreager.net/pdf/Lafont1997.pdf#page=5). So every interaction system is strongly confluent, and all reductions to normal form have the same length. *Inference:* confluence and orthogonality are not useful objective terms here, because every candidate already has them. The objective has to separate systems on other axes.

**Linear logic forces explicit copy and erase.** Girard: ["As soon as weakening and contraction have been forbidden, we are in linear logic"](https://girard.perso.math.cnrs.fr/linear.pdf#page=5). Without them ["the proofs diminish in size during normalization"](https://girard.perso.math.cnrs.fr/linear.pdf#page=6), so nothing interesting can be translated in. Copying and erasing return only through the exponentials: ["these modalities indicate the possibility of structural rules on the formula beginning with them"](https://girard.perso.math.cnrs.fr/linear.pdf#page=6). Interaction nets ["appeared as a generalization of Girard's proof nets for linear logic"](https://dcreager.net/pdf/Lafont1997.pdf#page=2), and Lafont asks ["is it reasonable to consider erasing and duplication as atomic operations"](https://dcreager.net/pdf/Lafont1997.pdf#page=2). His minimality argument (Section 1) is the nearest thing to "forced by axioms". Some rule must grow the net, some rule must empty it, and some rule must leave plain wiring, so a duplicator, an eraser and annihilation are each forced.

**Optimal reduction (Lévy, Lamping, Asperti).** Lévy's families define the ideal sharing. ["Family reduction has very nice properties: the most interesting one is that it satisfies a one-step diamond property"](https://arxiv.org/pdf/1701.04240#page=3), so the number of steps does not depend on the strategy. Lamping's sharing graphs ["performs the minimum amount of duplication"](https://arxiv.org/pdf/1701.04240#page=5) required. But Asperti warns that ["the length of family reduction is not a good measure of the intrinsic complexity"](https://arxiv.org/pdf/1701.04240#page=5) of terms. The bracket "bookkeeping" is open: ["It is conjectured that bookkeeping only adds a polynomial overhead"](https://arxiv.org/pdf/1701.04240#page=5). The worst-case cost is inherent: ["the non elementary cost of optimal reduction is not due to bookkeeping"](https://arxiv.org/pdf/1701.04240#page=5). *Inference:* optimality singles out one sharing *discipline*, not one rule set. As an objective term, "duplications performed" is principled, while "interactions performed" is not.

**Geometry of interaction.** Used here only through Mazza's observables (Section 1) and Lafont's reversible 2-stack machine reading. *Inference:* GoI gives a reduction-invariant meaning of a net as paths. An objective can use it to check that two candidate systems compute the same thing without running them to normal form.

## 6. Rules as data (brief)

- ρ-calculus (rewriting calculus): ["rules and strategies are abstractions of the same nature"](https://arxiv.org/pdf/1303.0796#page=3), so rules are ordinary terms.
- Port-graph ρpg-calculus (Andrei & Kirchner): a calculus ["whose first-class citizens are object port graphs, port graph rewrite rules and rule application"](https://inria.hal.science/inria-00328554/document#page=6). It permits ["rules that create new rules, providing a way of modeling emergence in a system"](https://inria.hal.science/inria-00328554/document#page=3).
- Maude: ["a reflective logic is a logic which can be faithfully interpreted in itself"](https://maude.lcc.uma.es/maude-manual/maude-manualch17.html#x114-233001). The cost is that ["each step up the reflective tower comes at considerable computational cost"](https://maude.lcc.uma.es/maude-manual/maude-manualch17.html#x114-234002), which is the interpretive overhead of Section 2 again.
- Self-modifying program soups (Agüera y Arcas et al.): when random programs are ["placed in an environment lacking any explicit fitness landscape, self-replicators tend to arise"](https://arxiv.org/pdf/2406.19108#page=1). But in one ["a minimalistic programming language where self-replicators are possible, but so far have not been observed to arise"](https://arxiv.org/pdf/2406.19108#page=1). They detect the transition with ["we introduce a novel complexity metric we call"](https://arxiv.org/pdf/2406.19108#page=4) "high-order entropy" (Shannon entropy minus compressed size).

## What to borrow

1. **Universality.**
   - Use Lafont's translation notion as a hard constraint, not a score. The candidate must simulate the interaction combinators, with each agent mapped to a principal net and step overhead bounded by constants L and M. The search can verify this by finding the six combinator translations.
   - Score L and M (the overhead constants) alongside agent and rule counts. Lafont's necessity invariants (some rule grows the net, some rule empties it, some rule leaves plain wiring) make cheap pruning filters.
2. **Self-interpreter size.**
   - Fix the representation of code before measuring, following Brown–Palsberg: total, injective, normal-form data. Then score the self-interpreter's size in one fixed encoding (Tromp's bits).
   - Add a Jones-style overhead term: interpreted steps divided by direct steps on a benchmark set. Guard against the "recognize sint" cheat by making the representation an input to the scoring, never something the candidate chooses.
3. **Rule-space search.**
   - Enumerate rule tables in TNF style: define a rule only when a reachable active pair needs it, and canonicalize agent renaming and port permutations.
   - Feed candidates to a pipeline of cheap deciders, as in BB(5): "dies", "loops", "translates the combinators", and so on. Keep the holdouts for manual review.
   - Fix an anti-triviality criterion up front, as Langton and Cook did. Self-reading must be done by the net, not hard-wired into one rule.
4. **Rule synthesis.**
   - Use Ruler-style fingerprints. Run every small candidate net on sample inputs and use the results as a cvec to bucket equivalent nets and propose identities. Prune with rules already found.
   - Use Massalin's two-stage check: a fast random test, then an exact check. For bounded rule sizes, encode "a rule table such that these nets reduce to these results" as SAT, following Zantema.
5. **Elegance criteria.**
   - Drop confluence from the objective, since every interaction system has it.
   - Take two principled cost terms from linear logic and optimal reduction: count duplication and erasure interactions separately from the rest, and prefer systems where copying is explicit and minimal.
6. **Rules as data.**
   - Use the ρpg-calculus as the reference design for a net that holds its own rules as subnets.
   - Price reflection by its tower overhead, the Maude cost. The soup experiment suggests a dynamic test: does self-reading emerge from random initial nets? It also warns that some minimal languages never show it.
