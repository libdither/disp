Bend Tetris

Tetris written in Bend 2. Its checker proves every loop in the game ends; here, Bend's JavaScript target runs it, and the same file opens a native window. Arrow keys move and rotate, space drops.

How it runs

The game is pure Bend. update folds one frame's key presses into the next game, and picture draws a game as an image: a quadtree of colored squares. Natively, Bend's App.run shows those pictures in a window 60 times a second. Here this page does the same job: it calls update every 1/60 s and paints each new picture on the canvas.

  1. tetris.bendPieces, rules, scoring, the font, and the picture.
  2. bend tetris.bendChecks types, use-once values, and that every recursion ends.
  3. bend web/index.html -o distCompiles the game to JavaScript and bundles it with this page.
  4. bend tetris.bend -o tetrisOr compiles it to C, for a native window.
