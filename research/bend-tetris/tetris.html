Bend Tetris

Tetris written in Bend, a functional language that runs on interaction nets, played here through its HVM2 runtime compiled to WebAssembly. Arrow keys move and rotate, space drops.

How it runs

The whole game is one Bend program. step takes a game and a key and returns the next game; draw turns a game into a screen of text. The loop in main reads a byte from stdin, steps, and prints the new frame. This page stands in for the terminal: it sends your keys, plus a zero byte every 50 ms for gravity, and paints the ANSI text that comes back.

  1. tetris.bendPieces, rules, scoring and drawing.
  2. bend gen-cCompiles the program to an interaction net, packaged with HVM2's C runtime.
  3. host.cRuns HVM on one thread and hands control back to JavaScript while the game waits for a key.
  4. zig cc -target wasm32-wasiBuilds the WebAssembly embedded in this page.
