# Every part of a reversible self-modifying fabric exists; nobody has put them together

**Is there research on graphs that read themselves with local rewrites?** Yes, and its main result is a limit. A process made of local rules that all run the same program learns only its *view*: the graph unrolled into an infinite tree from where it stands. Boldi and Vigna prove that ["no algorithm will ever be able to drive processors having the same universal total graph into distinct states"](https://vigna.di.unimi.it/ftp/papers/FibrationsOfGraphs.pdf#page=16), and for rules that add and remove edges, Klavins, Ghrist and Lipsky show that ["binary rules are insufficient to construct a unique stable cycle"](https://www2.math.upenn.edu/~ghrist/preprints/icra2004.pdf#page=3). An interaction-net rule (a rewrite that fires where two agents meet) is such a process, so no rule can learn "do these two wires end at the same node". *Inference:* the way out is a mark. One unique node breaks the symmetry, and opening a binder (applying a function to a fresh marker) is the cheapest mark there is. The graph systems that copy themselves (Tomita's graph-rewriting automata, Buliga's chemlambda, interaction-combinator quines) copy without reading. The one artificial chemistry in which a molecule reads another, Stringmol, works on strings walked by a head, not on graphs.

**What does "case" on a graph of λs and variables mean?** *Inference:* a local case branches on the node you stand on: its kind and the port you came in by. That is a finite set, the agent kinds. It cannot have an arm for "this use belongs to that binder"; only opening finds that out. Binding can still be split into finitely many local shapes, in two ways. Per application: where each variable goes (both sides, right only, left only, nowhere), which is S, B, C, K, as in [director strings](https://lsv.ens-paris-saclay.fr/Publis/PAPERS/PDF/FMS-aaecc05.pdf#page=5). Per binder: how many uses it has (none, one, many), which is eraser, plain wire, copier, as in [λ-graphs with jumps](https://lmcs.episciences.org/847/pdf#page=2).

**What would a self-modifying FPGA need, with data flowing reversibly on wires and signals that print, read or destroy cells?** Every piece exists in some paper, and no paper combines them. A signal that reads a cell by clearing it, with no garbage: Morita's rotary element. Copying onto a blank cell without heat: Bennett. Signals that print and destroy cells of the medium they run in: von Neumann's constructor, irreversibly. A token that rewrites the graph it walks: the dynamic geometry-of-interaction machine, irreversibly. Cells that rewrite each other's lookup tables: the Cell Matrix (2002 paper, an 8×8 hardware board), not reversible. One visitor per cell: Ackley's Movable Feast Machine and Peper's arbiters. Nothing found stores rewrite rules as matter that local rules read and rewrite. The closest is the Cell Matrix. *Inference:* its write already shifts the old bit out as the new one goes in, so a fabric that kept what comes out could undo every write. No paper says this.

How to read the rest. A linked statement is what the linked source says. *Inference:* marks reasoning no source states; it covers the rest of its paragraph or table cell, though a linked phrase inside it is still what the source says. *Measured* means a count from this repo: the reflective net (`research/linear-ic-net/nets/`, a λ-calculus run as an interaction net whose programs can read any function's code), its design notes (`DESIGN.md`) and its newer prototype (`tables.py`). Every quote was matched against its source by `scripts/verify-source.sh`; plain-text and anchorless pages carry a text fragment (`#:~:text=`). Nothing was built for this report. Words used throughout: a *blank* is an empty cell a print can fill; *garbage* is information a step leaves behind that nobody wants; an *active pair* is two agents joined at their principal ports, the only place an interaction-net rule fires.

## 1. Local rules learn the unrolled graph, so reading a graph needs a mark

Boldi and Vigna's processors sit on the nodes of a coloured, directed graph, all running one program and talking only to neighbours. Each can learn its view one level at a time; the algorithm ["consists in reading (at step k) from all neighbours their universal total graph truncated at depth k"](https://vigna.di.unimi.it/ftp/papers/FibrationsOfGraphs.pdf#page=16). It can never learn more: two nodes with the same view stay in the same state forever. With outgoing ports told apart, as in interaction nets, one node can be singled out exactly when the graph covers nothing smaller: the networks that admit an election ["are exactly those whose underlying graph is covering prime"](https://vigna.di.unimi.it/ftp/papers/FibrationsOfGraphs.pdf#page=11) (a *cover* is a bigger graph mapping onto G with every neighbourhood preserved, like two copies of a triangle glued into a hexagon). Chalopin and Métivier prove the same for the published model closest to an active pair, rules that rewrite the labels at both ends of one edge together: ["there exists an election algorithm for G if and only if G is minimal for the covering relation"](https://pageperso.lis-lab.fr/~jeremie.chalopin/publis/CM-DC10.pdf#page=3).

For rules that change structure, Klavins, Ghrist and Lipsky build graphs of robots from pairwise rules. Pairwise rules build trees; ["for a general graph we synthesize a ternary grammar"](https://www2.math.upenn.edu/~ghrist/preprints/icra2004.pdf#page=1), one whose rules see three nodes. The reason is again covers: anything a pairwise rule set can build, it can also build any cover of. *Inference:* a rule that sees two nodes cannot tell a cycle of length n from one of length 2n, so it cannot settle whether two wires meet at the same node.

*Inference:* a graph with one marked node covers nothing smaller (a cover would carry several marks), so with a mark everything becomes learnable, by spreading distinct names and comparing them. Opening a binder is that move with one name per binder. In term syntax it is the locally nameless style's opening: ["Variable opening turns some bound variables into free variables"](https://chargueraud.org/research/2009/ln/main.pdf#page=5). Trees read cleanly because a tree is its own view; a λ-graph with a back-wire from a variable to its binder is not, and reading it needs marks. Roots also make matching cheap: with a marked root, rules can ["be matched in constant time, provided that host graphs have a bounded node degree"](https://eprints.whiterose.ac.uk/id/eprint/195067/1/BakPlump.GraBaTs.12.pdf#page=3). An interaction net is the extreme case: the root is a principal port and the pattern is two agents.

Graph systems that copy or rebuild themselves:

| system | the graph | how a copy is made | is the description read? | are rules inside the graph? |
|---|---|---|---|---|
| graph-rewriting automata (Tomita, Kurokawa, Murata, 2002–2007) | every node has three links in a fixed order and a finite state; link rules rewire or delete the two nodes at a link | a construction arm, itself a subgraph, ["executes a program described in the graph structure"](https://eutils.ncbi.nlm.nih.gov/entrez/eutils/efetch.fcgi?db=pubmed&id=17716018&rettype=abstract&retmode=text#:~:text=construction%20arm): von Neumann's scheme | yes, as a tape inside the graph. *Inference:* every graph system found copies without reading. The only descriptions that get read are stored as strings or tapes. Rules stored in the graph exist (Tomita's metanodes, Stringmol code), but each time a fixed outer rule set interprets them; no source was found where local rules read and rewrite graph-shaped rules.

## 2. A case on a graph branches on one node and the port it was entered by

*Inference:* in an interaction net, the only thing one agent learns about another is which rule fired when they met. So a case is a family of rules, one per agent kind, and its arms are those kinds plus the port of entry. Section 1 rules out an arm for "this occurrence belongs to that binder": a two-agent rule cannot see where the other wires go. Opening gets that answer by marking, not by casing. What a case can branch on finitely is the local shape of binding, and the literature has two finite decompositions plus a non-finite one:

| decomposition | what each node records | finite? | source |
|---|---|---|---|
| routing per application, all variables at once | for each variable in scope, where it goes: both sides, right, left, nowhere (S, B, C, K) | four letters per variable, but a node's string grows with the number of variables in scope | director strings: ["Terms are annotated with information - directors - that indicate how substitutions should be propagated"](https://lsv.ens-paris-saclay.fr/Publis/PAPERS/PDF/FMS-aaecc05.pdf#page=1); ["S x y takes an argument and directs it to both x and y"](https://lsv.ens-paris-saclay.fr/Publis/PAPERS/PDF/FMS-aaecc05.pdf#page=5) |
| routing, one variable at a time | the same, with the variable then removed (bracket abstraction) | yes, but terms grow. Measured (`DESIGN.md`): λx1…x16. k x16…x1 is 50 agents as a net and 1,134 nodes in the project's 9-rule tree calculus | standard |
| uses per binder | how many uses: 0, 1, many, which is eraser, wire, copier | yes, three shapes, visible at the binder's variable port one wire away | λ-graphs with jumps: the three cases ["correspond, respectively, to weakening-box, dereliction-box and contraction-box"](https://lmcs.episciences.org/847/pdf#page=2) |
| uses per binder, exactly | the number and positions of all uses | no: a number at every node | Abel and Kraus: ["number and relative position of all occurrences of the bound variable are stored"](https://arxiv.org/pdf/1111.0085#page=1) |

Measured, in this project. The older reflective net reads a value with a reader agent that meets its top node and builds a five-argument function, one argument per kind of value; in a reading program a read costs about 2,070 rewrites, 97% of them copying and erasing code (see `Reading code in interaction nets.md` in this folder). The newer prototype, `nets/tables.py`, makes every function one agent that names a fixed definition plus its captured values (a closure), and reads through a "kept table" agent with six slots, one per kind of value (function, opened function, application, variable use, `ρ` the reflection primitive, table). The commit that added it (68255b2) reports about 11 rewrites per read. *Inference:* the kept table is exactly the finite local case of this section: six arms for six node kinds, with binding left to opening. Its awkward part, by the file's own rule list, is that the chosen slot is copied and one copy goes "back into a rebuilt tab" so a linear program gets its arms back. That cost comes from handing arms back, not from casing. The uses-per-binder split is the one finite case on binding the literature offers, and the net already shows it as wiring (an eraser, a plain wire or a `sig` splitter on the binder's variable port), so a case on it would need no new information.

## 3. Signals that read, print and destroy: every move exists somewhere

| move | reversible version | irreversible version |
|---|---|---|
| read | read-and-clear. Morita's rotary element is a bar in one of two positions; a particle that ["comes from the direction orthogonal to the bar"](https://arxiv.org/pdf/1309.1264#page=2) turns and rotates it. A machine's state is read by resetting it, ["after setting the bottom RE of the 1st column to V, the particle appears on the line"](https://arxiv.org/pdf/1309.1264#page=4), so the state leaves on the particle's path. Morita's survey calls such circuits ["completely garbageless"](https://web.archive.org/web/20170815133232id_/http://ir.lib.hiroshima-u.ac.jp/files/public/2/25576/20141016152033521657/TCS_395_101.pdf#page=11) | von Neumann's constructor (Pesavento's implementation): ["Because bit reading is a destructive operation"](https://fab.cba.mit.edu/classes/865.18/replication/Pesavento.pdf#page=5), the bit is written back afterwards |
| move a cell | in Morita's reversible cellular automaton P3, a marker ["can be pushed or pulled by one cell by giving an appropriate signal"](https://web.archive.org/web/20170815133232id_/http://ir.lib.hiroshima-u.ac.jp/files/public/2/25576/20141016152033521657/TCS_395_101.pdf#page=37), and a counter machine runs by ["a single signal that interacts with REs and position markers"](https://web.archive.org/web/20170815133232id_/http://ir.lib.hiroshima-u.ac.jp/files/public/2/25576/20141016152033521657/TCS_395_101.pdf#page=39). Needs empty space, no new blank | — |
| copy | onto a blank: it ["can be done reversibly if the tape used for the copy is initially blank"](https://mathweb.ucsd.edu/~sbuss/CourseWeb/Math268_2013W/Bennett_Reversibiity.pdf#page=2) (Bennett 1973) | over old contents: costly ["only when they are conducted in such a way as to overwrite previous information"](https://arxiv.org/pdf/physics/0210005#page=6) |
| un-copy | Bennett 2003 names both: ["copying unknown data onto a blank (ie initially zero) register, and the reverse process, namely erasure of one of two copies of data known to be identical"](https://arxiv.org/pdf/physics/0210005#page=2) | — |
| print | none found as a general mechanism. Morita and Imai's reversible self-reproduction builds by a fixed scheme (below) | Codd's signal at a wire's capped end ["results in the data-path being extended by one cell"](https://www-users.york.ac.uk/~gt512/BIC/langton84.pdf#page=4); the arm, swept over empty space, goes on ["setting the cells it passes over to the proper states"](https://www-users.york.ac.uk/~gt512/BIC/langton84.pdf#page=4) |
| destroy | inference: read-and-clear is print run backward, reversible only because the signal leaves carrying the cell's kind | von Neumann: an excitation ["results in a transition to the blank state"](https://fab.cba.mit.edu/classes/865.18/replication/Pesavento.pdf#page=11); the kind is lost |
| fan-out | only inside an explicit element: ["we shall require that any fan-out of signals take place within explicit signal-processing elements"](https://www.cs.princeton.edu/courses/archive/fall06/cos576/papers/fredkin_toffoli82.pdf#page=5); in Morita's circuits ["fan-out of an output is not allowed"](https://arxiv.org/pdf/1309.1264#page=4) | Codd and Langton's T-junctions copy every signal for free |

The accounting comes from Toffoli: ["each constant input entails the supply of energy of predictable form, or work"](https://cqi.inf.usi.ch/qic/80_Toffoli.pdf#page=6), and each garbage output the ["removal of energy of unpredictable form, or heat"](https://cqi.inf.usi.ch/qic/80_Toffoli.pdf#page=6). So blanks are work and garbage is heat. Two corrections to the plain sketch of "pass, print, print backward; erasing is the only heat":

1. **Passing a cell is itself a copy, into the signal.** A signal that notes a cell's kind needs a blank slot to note it in. Bennett's reversible measurement is exactly this, a step that, ["like the copying of a bit onto previously blank tape, does not overwrite information previously stored there"](https://www.cs.princeton.edu/courses/archive/fall06/cos576/papers/bennett82.pdf#page=23). *Inference:* a signal already holding a note cannot read again until it gives the note up.
2. **Erasing is the only heat you must pay, not the only heat.** Moving forward at a nonzero speed costs too: dissipation per step gives ["a net copying speed proportional to"](https://www.cs.princeton.edu/courses/archive/fall06/cos576/papers/bennett82.pdf#page=11) it. In Brownian circuits (tokens moved by thermal noise) a ratchet stops backward steps, and ["ratchets consume energy, as shown by Feynman"](https://www.cs.upc.edu/~jordicf/gavina/BIB/files/BrownianCircuits_JETC2013.pdf#page=20). *Inference:* a fabric run by noise pays at its commit points, such as finishing a print.

Blanks run out. In Hutton's Squirm3 (atoms that bond and react on a grid) copies stall when the right atoms are gone: they ["are unable to replicate further because there aren't any e0's left"](https://faculty.cc.gatech.edu/~turk/bio_sim/articles/hutton_rep_molecules.pdf#page=6). Reversible self-reproduction has been done: ["Self-reproduction is also possible in RCAs"](https://web.archive.org/web/20170815133232id_/http://ir.lib.hiroshima-u.ac.jp/files/public/2/25576/20141016152033521657/TCS_395_101.pdf#page=40) (reversible cellular automata), and the 3-D version can ["self-reproduce various patterns in three-dimensional reversible cellular space without dissipating garbage signals"](https://eutils.ncbi.nlm.nih.gov/entrez/eutils/efetch.fcgi?db=pubmed&id=12171635&rettype=abstract&retmode=text#:~:text=without%20dissipating%20garbage%20signals). It builds by a fixed reproduction scheme, not by general printing, and the 1996 paper's text could not be read (see the last section).

Tokens on nets sit at both ends. Danos and Regnier's interaction abstract machine sends a token through a net that never changes; it is bi-deterministic, ["So that the mechanism is reversible"](https://www.pure.ed.ac.uk/ws/portalfiles/portal/16874549/Reversible_irreversible_and_optimal_machines.pdf#page=4), and ["It needs no external garbage-collection"](https://www.pure.ed.ac.uk/ws/portalfiles/portal/16874549/Reversible_irreversible_and_optimal_machines.pdf#page=4). It reads only, and pays in recomputation. Muroya and Ghica's dynamic GoI machine ["interleaves token passing with graph rewriting"](https://arxiv.org/pdf/1803.00427#page=2), and ["the token holds control over graph rewriting"](https://arxiv.org/pdf/1803.00427#page=3): the nearest published model of a signal that rewrites the net it travels on. It is not reversible. For interaction nets as a whole, Salikhmetov's condition for a reversible system is that ["two active pairs never reduce to overlapping nets and any net can be the result of at most one active pair"](https://arxiv.org/pdf/1806.07275#page=4), and whether a universal one exists is open: ["One may wonder if there exists a reversible equivalent of interaction combinators"](https://arxiv.org/pdf/1806.07275#page=6).

## 4. Hardware that rewrites itself: the Cell Matrix comes closest

In the Cell Matrix (Macias and Durbeck) each cell is a lookup table with a data and a control line to each neighbour. Only neighbours write it: ["A cell's current mode is determined not by itself, but by its neighbors"](https://www.cellmatrix.com/entryway/products/pub/eh2002.pdf#page=3), and ["one cell can modify a neighboring cell's lookup table simply by placing that neighbor in C mode"](https://www.cellmatrix.com/entryway/products/pub/eh2002.pdf#page=3). A write is bit-serial: ["the configuration bit to be replaced next is presented to the cell's D outputs"](https://www.cellmatrix.com/entryway/products/pub/ForesightIOP.pdf#page=4), and ["the previous contents of the LUT are shifted out to the D outputs"](https://www-users.york.ac.uk/~gt512/Publications/2004/BioADIT04-Petraglio.pdf#page=5). Reading and writing are one operation, and a cell copies itself by ["inspecting its own truth table and copying it to another cell"](https://www-users.york.ac.uk/~gt512/Publications/2004/BioADIT04-Petraglio.pdf#page=4). The MOD 88 board ["is a hardware implementation of an 8x8 matrix of Cell Matrix cells"](https://www.cellmatrix.com/entryway/products/mod88/mod88.html#:~:text=8x8%20matrix%20of%20Cell%20Matrix%20cells).

*Inference:* that write is a swap, new bit in and old bit out. Keep the bits that come out instead of dropping them and every write can be undone. No Cell Matrix paper says this. What the Cell Matrix lacks for the fabric in question:

- **Arbitration.** Two writers at once are mixed: ["D inputs on all sides where Cin = 1 are ORd"](https://www.cellmatrix.com/entryway/products/pub/ForesightIOP.pdf#page=4).
- **Blanks and a place for garbage.** A cell is never empty, only an inert table; shifted-out bits go nowhere in particular.
- **Rules instead of lookup tables.** *Inference:* a table maps a cell's inputs to its outputs each clock; an interaction rule replaces two agents by others and rewires them. The Cell Matrix stores the first kind as matter, never the second.

| system | who writes a cell's configuration | one visitor per cell | blanks | garbage | reversible |
|---|---|---|---|---|---|
| Cell Matrix (8×8 board) | neighbours, bit by bit, as a swap | no: concurrent writers are ORed | no | none | no (the swap could be, inference) |
| POEtic (Thoma and Sanchez; chip) | ["In Configure mode, the molecule can partially reconfigure a neighbouring molecule"](http://web.cecs.pdx.edu/~mperkows/CAPSTONES/Poetic/thoma04prototyping.pdf#page=3), and an on-chip processor | the target ["chooses the source of the configuration data"](http://web.cecs.pdx.edu/~mperkows/CAPSTONES/Poetic/thoma04prototyping.pdf#page=3) | no | no | no |
| Movable Feast Machine (Ackley) | atoms, but element behaviour is fixed: ["Element definitions (compiled to non-volatile memory)"](https://www.usenix.org/legacy/event/hotos11/tech/final_files/Ackley.pdf#page=3) | yes: rules are ["able to read and write only inside the event window"](https://www.usenix.org/legacy/event/hotos11/tech/final_files/Ackley.pdf#page=3), and ["an indefinite number of nonoverlapping windows may occur in parallel"](https://www.usenix.org/legacy/event/hotos11/tech/final_files/Ackley.pdf#page=2) | yes: the DReg element makes resource atoms in empty sites | DReg ["probabilistically may delete an atom in a nearby site"](https://www.usenix.org/legacy/event/hotos11/tech/final_files/Ackley.pdf#page=3) | no: deletion is the point |
| asynchronous cellular arrays (Peper, Lee and others) | not built; named as the open problem (below) | an arbitration primitive in the rules: ["arbitration is necessary to ensure that signals on crossing paths can pass the crossing"](https://web.archive.org/web/20170706053101id_/http://web.cecs.pdx.edu/~mperkows/CLASS_573/Asynchr_Febr_2007/t30412.pdf#page=7) | no | no | no |
| Embryonics (Mange and others) | nobody at run time; each cell holds the whole program and, ["given the proper coordinates, it can execute any one of the genes of the operative genome"](https://www.cs.virginia.edu/~evans/bio-seminar/Embryonics_ProcIEEE.pdf#page=3) | synchronous | spare columns | faulty cells skipped | no |
| Xilinx self-reconfiguration over the internal port | one port driven by a processor; ["a frame is the smallest unit of reconfiguration"](https://eric-keller.github.io/papers/pre/ekeller_srp_fpl03.pdf#page=3), and ["Modifying one LUT on the XC2V1000 will take 13us for the read"](https://eric-keller.github.io/papers/pre/ekeller_srp_fpl03.pdf#page=9) | the region being loaded is cut off | — | — | no |
| Self-Reconfigurable Gate Array (Sidhu and others; simulated only) | any logic in the array, which ["can generate configuration bits at runtime and use them to modify its own configuration"](http://www.cs.ucr.edu/~kmiller/references/sidhu00selfreconfigurable.pdf#page=1) | a per-cell mask bit | — | — | no |
| FlatTop (adiabatic billiard-ball chip) | nobody: the rule is wired in and the program is the start state; ["not a very practical architecture for performing arbitrary computations"](https://people.csail.mit.edu/nhm/flattop.pdf#page=1) | synchronous | — | none needed | yes, but its rule never changes |

Peper and colleagues state the problem directly. Their asynchronous array paper ["leaves open the challenge of configuring the inherently homogeneous cellular hardware"](https://web.archive.org/web/20170706053101id_/http://web.cecs.pdx.edu/~mperkows/CLASS_573/Asynchr_Febr_2007/t30412.pdf#page=15), and names two routes: cells with a configuration mode, where ["Configuration is then achieved by rewriting the memories from cell to cell"](https://web.archive.org/web/20170706053101id_/http://web.cecs.pdx.edu/~mperkows/CLASS_573/Asynchr_Febr_2007/t30412.pdf#page=15) as in the Cell Matrix, or cells copying information collectively, close to self-reproduction. Takada, Isokawa, Peper and Matsui took the second route; Fatès's survey reports ["the existence of an asynchronous, rotation-symmetric rule with 15 states"](https://arxiv.org/pdf/1406.0792#page=12) that is universal for construction and computation. Those rules are not reversible.

Every working functional-language machine keeps rules fixed and the program in a side memory. In the Reduceron, an FPGA graph reducer, ["The bytecode for a whole program is simply the concatenation of the bytecodes"](https://www.doc.ic.ac.uk/~wl/teachlocal/arch/papers/reduceron08.pdf#page=4) of its functions, and running code never writes it. Embryonics' genome is the same idea in a cell array. No interaction net on an FPGA or ASIC was found in print, and no reversible hardware that changes its own rules was found.

## 5. What it adds up to

*Inference:* each column of the table above has an owner and no row fills them all. Cell Matrix and POEtic have configuration as matter, the Movable Feast Machine and Peper's arrays have one visitor per cell, the Movable Feast Machine alone has blanks and garbage handling, and FlatTop alone is reversible. Rules as matter is missing everywhere in the strong sense: lookup tables are matter in the Cell Matrix, and Tomita's metanodes store rules in the graph, but no system has local rewrite rules that are read and rewritten by local rewrite rules.

This project already has two of the pieces. Rewrites that can be undone exist in the strand evaluators (`evaluators/rust-ic-strands/crate/src/rev.rs`, the interaction-net evaluator for tree calculus): every rewrite remembers what it consumed, and erasing a copy's output is an "un-copy" event, Bennett's free reverse of copying. Copying is a walking signal everywhere in the project: a duplicator agent moves down what it copies, one rewrite per agent. *Measured* (`DESIGN.md`), one limit: the reflective net itself cannot be run backward. "Of the 33 rules, 5 make no agent", and 14 leave a result another rule also leaves, so "A run cannot" be had back; only the reversible adds hand back their inputs, as answers. An earlier design study, `research/SIGNAL_FABRIC.md`, costs a self-configuring circuit in energy, time and error but does not treat reversible writes.

## 6. Sketch of the fabric nobody has built (design, not sourced)

Everything in this section is *Inference*: a design put together from the parts above, not a result from any source.

| part | borrowed from | what it does here |
|---|---|---|
| cell | Cell Matrix, Movable Feast Machine | a site holding one agent (its kind and which way each port leaves), a piece of wire, or nothing (a blank) |
| write as a swap that keeps the old contents | Cell Matrix's shift-out, Bennett's copy onto a blank | a write puts the new contents in and sends the old ones out on the signal or into a kept slot, so the write can be undone |
| one visitor per cell | Peper's arbiter, Ackley's event window | a signal locks a cell before touching it; two signals reaching one cell are ordered by an arbiter element |
| blanks as the resource | Toffoli, Squirm3, the Movable Feast Machine | printing uses up a blank; read-and-clear gives one back |
| print only at the tip of an arm | Codd, Langton, von Neumann | an arm is a wire path; a signal at its capped end extends it by one cell or prints an agent there, and the inverse signal retracts it |
| read-and-clear as the read | Morita's rotary element | reading empties the cell and the signal carries the kind away; read-and-keep is read-and-clear, copy onto a blank slot in the signal, print back |

An active pair, under this sketch. Two agent cells whose principal ports are joined by a wire path form a pair. (1) A signal leaves one principal port, runs along the wire, and locks both cells. (2) It reads-and-clears both agents, so it now carries their two kinds and the ends of their auxiliary wires; two blanks are freed. (3) It looks up the rule, which, as in every working system above, is fixed in each cell's logic. (4) It extends arms into blank cells, prints the right-hand side's agents at their tips, and splices the auxiliary wires onto them. (5) It unlocks. The step is reversible without any history exactly when the rule table meets Salikhmetov's condition (no two pairs give overlapping results, and every result comes from at most one pair). Otherwise the signal must leave a history cell behind, as `rev.rs` keeps events, and that history is garbage that consumes blanks or must be erased as heat. A duplicator works as it does in the net, as a signal that prints copies at an arm tip, consuming blanks, while un-copy returns them.

Open problems:

- **Rules as matter.** If a rule is stored in cells, something reads those cells, and that reader's rules are fixed, as with Tomita's metanodes and Stringmol's machine. The regress stops at a fixed interpreter; the question is how small it can be, and whether it can be an interaction-net rule table itself.
- **Heat budget.** Garbage from rules that are not one-to-one, plus the drive to move forward. By `DESIGN.md`, a history for one tree add would be 4,636 marks for an answer of 252 agents. Commit points (finishing a print, unlocking) are where ratchets, and so heat, would go.
- **Who supplies blanks.** A reversible fabric can only reclaim cells by running work backward. The Movable Feast Machine's supply is random deletion (irreversible); Squirm3 shows the stall when the supply stops; a boundary feed is possible but makes the fabric's edges special.
- **Arbitration is a choice.** Ordering two signals that reach one cell decides something; reversibly, that decision has to be recorded somewhere.
- **Wires in a plane.** Interaction nets are not planar, so wire paths cross; crossings need an element of their own, which Peper's arbiters provide for crossing signals, and long wires make a pair's lookup slow.
- **Universality.** No universal reversible interaction system is known (Salikhmetov's open question), so the rule table cannot yet be both reversible and universal without a history.
